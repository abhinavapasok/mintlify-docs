Record and manage business expenses with payment details, categories, notes, and supporting documents.

<Note>
  The Expenses module allows you to record business expenses by entering the expense date, category, payment details, amount, and supporting documents.
</Note>

## Overview

The Expenses module helps you record and track money spent by your business.

You can use this module to:

- Record an expense
- Select the expense date
- Select an expense category
- Select the payment mode
- Select the account from which the expense was paid
- Enter the expense amount
- Add notes
- Upload supporting documents
- Keep expense records for reference

## Before you start

- **Permission needed:** Access to the **Expenses** module.
- **Settings to review:** Make sure the required expense categories, payment modes, and payment accounts are configured before recording an expense.

Key concepts

| Term | Meaning |
| --- | --- |
| Expense | Money spent by the business for goods, services, or other business-related costs. |
| Expense category | The category used to classify the expense. |
| Payment mode | The method used to make the expense payment. |
| Expense made from | The payment account from which the expense was paid. |
| Expense amount | The amount spent for the expense. |
| Attachment | A supporting image or PDF related to the expense. |
| Notes | Additional information about the expense. |

Common workflows

**Record an expense**

Use the **Expenses** module to record money spent by the business.

1. Open **Expenses** from the navigation menu.
2. Click **Add Expense**, if required.
3. Select the **Expense date**.
4. Select the **Category**.
5. Select the **Payment mode**.
6. Select the account in **Expense made from**.
7. Enter the **Expense amount**.
8. Add **Notes**, if required.
9. Upload supporting documents under **Attachments**, if required.
10. Review the entered information.
11. Click **Create Expense**.

## Add an expense category

You can add a new expense category while recording an expense.

1. Open the **Category** field.
2. Click the **\+** button next to the category field.
3. Enter the required category details.
4. Save the category.
5. Select the newly created category for the expense.

## Add a payment account

The **Expense made from** field identifies the account used to pay the expense.

1. Select the required payment account.
2. If a new account needs to be created, use the **\+** option when available.
3. Enter the required account details.
4. Save the account.
5. Select the account for the expense.

## Add supporting documents

You can attach documents related to an expense, such as receipts or bills.

1. Go to the **Attachments** section.
2. Click **Choose Files**.
3. Select the required images or PDF files.
4. Verify that the files are attached to the expense.
5. Complete the expense entry.

<Note>
  The Expenses screen allows a maximum of **5 files**, with a maximum size of **10 MB per file**.
</Note>

Field reference

| Field | What it does |
| --- | --- |
| Expense date | Specifies the date on which the expense occurred. |
| Category | Classifies the expense. |
| Payment mode | Specifies how the expense was paid. |
| Expense made from | Specifies the account from which the expense was paid. |
| Expense amount | Specifies the amount spent. |
| Notes | Adds additional information about the expense. |
| Attachments | Allows supporting images or PDF documents to be uploaded. |
| Choose Files | Opens the file selection option for uploading supporting documents. |
| Create Expense | Saves the expense record. |
| Cancel | Cancels the expense entry without creating the record. |

# FAQs

### What is the Expenses module used for?

The Expenses module is used to record and track money spent by the business.

### Is the expense date required?

Yes. **Expense date** is a required field.

### Is the expense category required?

Yes. **Category** is a required field.

### Is the payment mode required?

Yes. **Payment mode** is a required field.

### Is the expense amount required?

Yes. **Expense amount** is a required field.

### Can I add a new expense category?

Yes. Click the **\+** button next to the Category field to add a new category.

### Can I add notes to an expense?

Yes. You can enter additional information in the **Notes** field.

### Can I upload a receipt or other supporting document?

Yes. You can upload images or PDF files in the **Attachments** section.

### How many files can I attach to an expense?

You can upload up to **5 files**, with a maximum size of **10 MB per file**.

### What happens if I do not enter all required information?

The **Create Expense** button remains unavailable until the required fields are completed.
