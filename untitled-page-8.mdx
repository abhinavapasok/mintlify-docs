View your current KomKits subscription plan, plan limits, billing period, and payment history.

<Note>
  The Billing page displays the subscription currently associated with your KomKits account and the features and limits included in the plan.
</Note>

## Overview

The **Billing** page allows you to view and manage your KomKits subscription.

You can use this page to:

- View the current subscription plan
- Check the plan status
- View the subscription price
- View the current billing period
- Review the features and limits included in the plan
- Change the subscription plan
- View subscription payment history

## Current plan

The **Current plan** section displays information about the active subscription.

### Plan name

Displays the name of the current subscription plan.

For example, the current account is using the **Seed** plan.

### Plan status

Displays whether the subscription is currently active.

### Price

Shows the subscription price and billing frequency.

For example:

**₹0.00 / monthly**

### Current period

Shows the start and end dates of the current subscription period.

### Change Plan

Click **Change Plan** to view the available subscription plans and select a different plan.

# Payments

The **Payments** section displays payments made for the KomKits subscription.

If there are no subscription payments, the page displays a message indicating that payments will appear here when applicable.

# Common workflows

## View your current plan

1. Open **Billing** from the Admin section.
2. Review the **Current plan** section.
3. Check the plan name and status.
4. Review the price and current billing period.

## Check plan limits

1. Open **Billing**.
2. Go to **What's included**.
3. Review the available limits for:
   - Users
   - API keys
   - Locations
   - Transactions per month

## Change your subscription plan

1. Open **Billing**.
2. Click **Change Plan**.
3. Review the available plans.
4. Select the required plan.
5. Complete the plan change process.

# Field reference

| Field | What it does |
| --- | --- |
| Current Plan | Displays the subscription plan currently associated with the account. |
| Status | Shows whether the plan is active. |
| Price | Displays the subscription price and billing frequency. |
| Current Period | Shows the current subscription period. |
| Users | Shows the number of users included in the plan. |
| API Keys | Shows the number of API keys included in the plan. |
| Locations | Shows the number of locations included in the plan. |
| Transactions per month | Shows the number of transactions allowed per month. |
| Payments | Displays subscription payment records. |

# FAQs

### Where can I view my current subscription plan?

Open **Admin → Billing** to view your current plan.

### Where can I see the plan price?

The plan price is displayed under **Current plan**.

### How can I check what my plan includes?

Review the **What's included** section on the Billing page.

### Can I change my subscription plan?

Yes. Click **Change Plan** to view the available plans.

### Where can I view my subscription payments?

Subscription payment records are displayed in the **Payments** section.

### Does the Billing page show my current usage?

The current screen indicates that the displayed limits show what the plan allows and that **current usage is not available yet**.
