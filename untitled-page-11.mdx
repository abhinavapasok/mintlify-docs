title: "Content Template"
---

Create and manage reusable content templates for generating standardized business documents and outputs.

<Note>
  Select a template type before adding the template content. The selected template type enables the relevant AI assistance and variable suggestions.
</Note>

## Overview

The **Content Templates** module allows you to create reusable templates using HTML, JSON, or plain text content.

You can use content templates to:

- Create reusable document templates
- Select a template type
- Define a template name
- Add template content
- Use AI assistance when available
- Preview the template
- Use variables in templates
- Select the required output format
- Select the content type
- Validate and format the template before creating it

## Before you start

- Make sure you have permission to access **Content Templates**.
- Determine the type of template you want to create.
- Prepare the required template content.
- If you want to use AI assistance, make sure the required AI configuration is available.

## Key concepts

| Term | Meaning |
| --- | --- |
| Template | Reusable content used to generate a standardized output. |
| Template type | Defines the type or purpose of the template. |
| Template name | Identifies the template. |
| Source Code | The HTML, JSON, or plain content used to define the template. |
| Preview | Displays how the template content will appear. |
| Variable | A placeholder that can be replaced with relevant data when the template is used. |
| AI Assist | Helps create or edit template content using AI. |
| Output format | Defines the format in which the template output is generated. |
| Content type | Defines the type of content used by the template. |

# Common workflows

## Create a content template

1. Open **Content Templates** from the navigation menu.
2. Click **Add Content Template**.
3. Select the required **Template Type**.
4. Enter a **Name** for the template.
5. Add the template content in the **Source Code** section.
6. Use variables where required.
7. Click **Preview** to review the template.
8. Open **Advanced Settings**.
9. Select the required **Output Format**.
10. Select the required **Content Type**.
11. Validate or format the template if required.
12. Click **Create Template**.

## Add template content

1. Select a template type.
2. Enter the required content in the **Source Code** editor.
3. Add supported variables where dynamic information is required.
4. Review the content.
5. Use **Preview** to check the output.

<Note>
  The Source Code editor supports HTML, JSON, or plain body content depending on the template configuration.
</Note>

## Use AI Assist

1. Select a **Template Type**.
2. Click **AI Assist**.
3. Provide the required instruction or select the content to be modified.
4. Review the AI-generated or modified content.
5. Update the template if required.

<Note>
  AI Assist and variable suggestions become available after selecting a template type.
</Note>

## Preview a template

1. Enter the template content.
2. Select the **Preview** tab.
3. Review the generated preview.
4. Return to **Source Code** to make changes if required.

# Advanced settings

The **Advanced Settings** section allows you to define how the template content should be processed.

### Output format

Select the required output format from the available options.

For example, the screen currently shows **PNG** as the selected output format.

### Content type

Select the type of content used by the template.

For example, the screen currently shows **text/html**.

# Field reference

| Field | What it does |
| --- | --- |
| Template Type | Selects the type of template being created. |
| Name | Identifies the content template. |
| AI Assist | Provides AI assistance for creating or editing template content. |

| Action | Description |
| --- | --- |

| **Validate** | Checks the template content for validation issues. |

# FAQs

### Why do I need to select a template type first?

Selecting a template type enables the relevant AI assistance and variable suggestions for the template.

### Can I preview the template before creating it?

Yes. Use the **Preview** tab to review the template output before creating the template.

### Can I use variables in a template?

Yes. Supported variables can be added to the template content to insert dynamic information when the template is used.

### What type of content can I add?

The Source Code section supports **HTML, JSON, or plain body content**, depending on the template configuration.

### Can I use AI to create or edit template content?

Yes. The **AI Assist** option can be used after selecting a template type.

### Can I validate the template before creating it?

Yes. Use the **Validate** option to check the template before creating it.

### Can I format HTML content?

Yes. When applicable, use **Format HTML** to format the template's HTML content.

### What is the purpose of Output Format?

Output Format determines the format in which the template output is generated.
