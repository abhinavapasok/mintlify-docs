Add and manage users who can access your KomKits business account.

<Note>
  User access is controlled through the user role assigned to each user. Make sure the appropriate role is selected when adding a user.
</Note>

## Overview

The **Manage Users** section allows administrators to add and manage users who need access to the KomKits account.

You can use this module to:

- Add new users
- Enter user contact information
- Set a password for a user
- Assign a user role
- View existing users
- Manage user access

## Before you start

- Make sure you have permission to access **Manage Users**.
- Have the user's name, email address, and phone number available.
- Make sure the required user role has already been created before assigning it.

## Key concepts

| Term | Meaning |
| --- | --- |
| User | A person who has access to the KomKits business account. |
| User role | Defines the permissions and access available to a user. |
| Full name | The name of the user. |
| Email | The user's email address. |
| Phone number | The user's contact phone number. |
| Password | The password used by the user to access the account. |

# Common workflows

## Add a new user

1. Open **Manage Users** from the Admin section.
2. Click **Add User**.
3. Enter the user's **Full Name**.
4. Enter the user's **Email** address.
5. Select the country code and enter the **Phone Number**.
6. Enter the user's **Password**.
7. Select the appropriate **User Role**.
8. Review the information.
9. Click **Add**.

## Assign a role to a user

1. Open **Manage Users**.
2. Click **Add User** or open the user details.
3. Select the required **User Role**.
4. Review the assigned access.
5. Save the changes.

<Note>
  The permissions available to a user depend on the role assigned to them.
</Note>

Field reference

| Field | Required | What it does |
| --- | --- | --- |
| Profile image | No | Adds an image for the user. |
| Full name | No\* | Identifies the user. |
| Email | No\* | Stores the user's email address. |
| Phone number | Yes | Stores the user's contact number. |
| Password | No\* | Sets the user's login password. |
| User role | No\* | Assigns the user's role and associated permissions. |

# FAQs

### Who can add a new user?

Users with the required permission to access **Manage Users** can add new users.

### Can I assign a role while creating a user?

Yes. Select the required role in the **User Role** field before clicking **Add**.

### Is a phone number required?

Yes. The **Phone number** field is marked as required in the current form.

### Can I upload a profile image?

Yes. The user form provides an option to add a profile image.

### What determines what a user can access?

The user's assigned **role and its permissions** determine their access within KomKits.

### Can I change a user's role later?

 The user's role can be updated from their user details.
