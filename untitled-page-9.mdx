title: "Payment Account"
---

Manage the accounts used to record money received, money paid, and other payment transactions in KomKits.

<Note>
  Payment accounts are used when recording payments and in supported sales and purchase transactions. Configure the appropriate account details before using an account in transactions.
</Note>

## Overview

The **Payment Account** module allows you to create and manage accounts used for receiving and paying money.

You can use this module to:

- Create payment accounts
- Select an account type
- Set an opening balance
- Add bank account details
- Record account holder information
- Add a UPI ID
- View account details
- Increase or decrease an account balance
- Transfer money between payment accounts

## Before you start

- Make sure you have permission to access **Payment Account**.
- Keep the required bank or payment account details available when creating an account.
- Select the appropriate account type based on how the account will be used.

## Key concepts

| Term | Meaning |
| --- | --- |
| Payment account | An account used to record money received or paid. |
| Account name | The name used to identify the payment account. |
| Account type | Defines the type of payment account. |
| Opening balance | The balance available in the account when it is created. |
| Bank account number | The bank account number associated with the account, when applicable. |
| Bank branch name | The branch associated with the bank account. |
| Account holder name | The name of the person or business that owns the account. |
| UPI ID | The UPI identifier associated with the payment account. |

# Account types

KomKits provides the following account types:

- **Cash**
- **Bank**
- **Credit Card**
- **Debit Card**
- **Cheque**

Select the account type that matches the payment account you are creating.

# Common workflows

## Add a payment account

1. Open **Payment Account** from the Admin section.
2. Click **Add Account**.
3. Enter the **Account Name**.
4. Select the **Account Type**.
5. Enter the **Opening Balance**, if applicable.
6. Enter the relevant account details.
7. Enter the **Bank Branch Name**, if applicable.
8. Enter the **Account Holder Name**.
9. Enter the **UPI ID**, if applicable.
10. Review the information.
11. Save the payment account.

## Add a bank account

1. Open **Payment Account**.
2. Click **Add Account**.
3. Enter the **Account Name**.
4. Select **Bank** as the **Account Type**.
5. Enter the **Opening Balance**.
6. Enter the **Bank Account Number**.
7. Enter the **Bank Branch Name**.
8. Enter the **Account Holder Name**.
9. Enter the **UPI ID**, if applicable.
10. Save the account.

## View account details

1. Open **Payment Account**.
2. Locate the required account.
3. Click **View Account Details**.
4. Review the account information and balance.

## Add or reduce an account balance

1. Open **Payment Account**.
2. Select the required account.
3. Click **Add/Reduce Amount**.
4. Select whether to add or reduce the amount.
5. Enter the required amount.
6. Review the updated balance.
7. Save the adjustment.

## Transfer money between accounts

1. Open **Payment Account**.
2. Click **Transfer Money**.
3. Select the source account.
4. Select the destination account.
5. Enter the transfer amount.
6. Review the transfer details.
7. Confirm the transfer.

# Field reference

| Field | What it does |
| --- | --- |
| Account Name | Identifies the payment account. |
| Account Type | Defines whether the account is Cash, Bank, Credit Card, Debit Card, or Cheque. |
| Opening Balance | Sets the initial balance of the account. |
| Bank Account Number | Stores the associated bank account number. |
| Bank Branch Name | Stores the bank branch information. |
| Account Holder Name | Identifies the account holder. |
| UPI ID | Stores the UPI ID associated with the account. |

# FAQs

### What types of payment accounts can I create?

You can create **Cash, Bank, Credit Card, Debit Card, and Cheque** accounts.

### What is the opening balance?

The opening balance is the amount available in the account when it is created.

### Do I need to enter bank details for every account?

No. Bank-specific information is applicable when creating an account that requires those details.

### Can I change the account balance manually?

Yes. The **Add/Reduce Amount** option can be used to adjust an account balance.

### Can I transfer money between payment accounts?

Yes. Use the **Transfer Money** option to transfer an amount from one payment account to another.

### Where are payment accounts used?

Payment accounts can be selected when recording payments and in supported sales and purchase transactions.
