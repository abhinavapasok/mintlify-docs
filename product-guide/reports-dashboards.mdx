## Overview

## Overview

The **Dashboard** provides a quick summary of important business information in one place.

You can use the Dashboard to:

- View total sales
- View quotation activity
- View income and expenses
- Check payment status
- View sales order activity
- Check quotation conversion
- Monitor payment completion
- View unconverted quotations
- Switch between different dashboard views

## Dashboard views

The Dashboard provides different views that can be selected from the top navigation.

Available views shown on the current dashboard include:

- **Overview**
- **Finance**
- **Reports**
- **Test Dashboard**
- **Demo**

Use the available tabs to switch between different dashboard views.

## Overview dashboard

The **Overview** tab provides a summary of the current business activity.

### Total sales

Displays the total sales amount for the current month.

It also shows:

- Number of invoices created this month
- Number of paid invoices

### Quotations

Displays quotation activity for the current month.

It shows:

- Total number of quotations
- Number of quotations converted
- Total quoted amount

### Income

Displays the total income recorded for the current month.

### Expense

Displays the total expenses recorded for the current month.

# Payment status

The **Payment Status** section provides a visual summary of payments against sales invoices.

It displays:

- Percentage of invoices paid
- Total amount paid
- Number of paid invoices
- Total amount unpaid
- Number of unpaid invoices

For example, the current dashboard shows **100% Paid**, with all displayed invoices marked as paid.

# This month

The **This Month** section provides additional business activity for the current month.

### Sales orders

Displays:

- Number of sales orders
- Total sales order amount

### Quotation conversion

Shows how many quotations have been converted into invoices.

It displays:

- Number of invoices created from quotations
- Total number of quotations
- Conversion percentage

### Payment completion

Displays the percentage of total sales that has been paid.

### Unconverted quotations

Shows the number of quotations that have not yet been converted into invoices.

# Common workflows

## Check monthly sales

1. Open **Dashboard**.
2. Select **Overview**.
3. Review the **Total sales** card.
4. Check the number of invoices created.
5. Review the number of paid invoices.

## Check payment status

1. Open **Dashboard**.
2. Go to the **Payment status** section.
3. Review the paid percentage.
4. Check the paid amount.
5. Check the unpaid amount and invoice count.

## Check quotation conversion

1. Open **Dashboard**.
2. Review the **Quotations** card.
3. Check the **Quotation conversion** section.
4. Review the number of converted quotations and the conversion percentage.

## Check monthly business activity

1. Open **Dashboard**.
2. Review the **This month** section.
3. Check sales orders.
4. Review quotation conversion.
5. Check payment completion.
6. Review unconverted quotations.

# Field reference

| Dashboard section | What it shows |
| --- | --- |
| Total sales | Total sales amount and invoice activity for the current month. |
| Quotations | Number and value of quotations and their conversion activity. |
| Income | Total income recorded for the current month. |
| Expense | Total expenses recorded for the current month. |
| Payment status | Paid and unpaid invoice amounts and percentages. |
| Sales orders | Number and total amount of sales orders for the current month. |
| Quotation conversion | Percentage and count of quotations converted into invoices. |
| Payment completion | Paid share of total sales. |
| Unconverted quotations | Quotations that have not yet been converted into invoices. |

# FAQs

### What information is available on the Dashboard?

The Dashboard provides a summary of sales, quotations, income, expenses, payments, sales orders, and quotation conversion.

### Does the Dashboard show monthly information?

Yes. The Overview and **This month** sections display current-month business activity.

### Can I check unpaid invoices from the Dashboard?

Yes. The **Payment status** section displays the unpaid amount and number of unpaid invoices.

### Can I see quotation conversion?

Yes. The Dashboard includes **Quotation conversion**, which shows the conversion activity and percentage.

### Can I switch to another dashboard view?

Yes. Use the tabs at the top of the Dashboard, such as **Finance** and **Reports**, where available.

### Does the Dashboard update when transactions change?

Dashboard figures are based on the available business transaction data and can change when transactions are created or updated.
