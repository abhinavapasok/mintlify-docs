Manage staff details, attendance, salary, payroll, and staff-related transactions.

<Note>
  The Staff module allows you to create and manage staff records, track attendance, manage salary information, make salary payments, and view staff transactions.
</Note>

## Overview

The **Staff** module helps you maintain employee information and manage staff-related activities.

You can use this module to:

- Add and manage staff
- Store staff contact and salary information
- Set salary payout type and salary cycle
- Track staff attendance
- Manage payroll
- Make salary payments
- View staff transactions
- Download salary slips
- Edit or delete staff records

## Before you start

- **Permission needed:** Access to the Staff module.
- Make sure the required staff and salary information is available before creating a staff record.
- Configure the appropriate salary payout type and salary cycle when adding staff.

Key concepts

| Term | Meaning |
| --- | --- |
| Staff | An employee or worker registered in the business. |
| Employee ID | A unique ID assigned to the staff member. |
| Salary | The amount payable to the staff member. |
| Salary payout type | Defines how often the salary is paid, such as monthly. |
| Salary cycle | Defines the period used to calculate the staff salary. |
| Joining date | The date on which the staff member joined the business. |
| Attendance | Records the staff member's daily attendance status. |
| Payroll | Information related to salary calculation and payment. |
| Transaction | Records salary payments or other staff-related financial transactions. |
| Opening balance | The initial outstanding or payable amount associated with the staff member. |

# Common workflows

## Add a staff member

Use **Add Staff** to create a new staff record.

1. Open **Staff** from the navigation menu.
2. Click **Add Staff**.
3. Enter the **Name**.
4. Enter the **Mobile number**.
5. Enter the **Email**, if applicable.
6. Select the **Salary Payout Type**.
7. Select the **Salary Cycle**.
8. Enter the **Salary**.
9. Select the **Type**.
10. Select the **Joining date**.
11. Enter the **Outstanding/Opening balance**, if applicable.
12. Click **Save**.

### Staff fields

| Field | What it does |
| --- | --- |
| Name | Identifies the staff member. |
| Mobile number | Stores the staff member's contact number. |
| Email | Stores the staff member's email address. |
| Salary payout type | Defines the salary payment frequency. |
| Salary cycle | Defines the salary calculation/payment cycle. |
| Salary | Specifies the staff member's salary amount. |
| Joining date | Records the staff member's joining date. |
| Type | Defines whether the amount is to be paid or received. |
| Outstanding/Opening balance | Records an existing balance associated with the staff member. |

# Staff details

After creating a staff member, open the staff record to view detailed information.

The Staff Details page displays:

- Employee ID
- Staff name
- Mobile number
- Salary
- Salary type
- Salary payout type
- Salary cycle
- Joining date
- Staff status

The page also provides actions such as:

- **Download Salary Slip**
- **Make Payment**
- **Edit**
- **Delete**

## Download salary slip

1. Open the required staff record.
2. Click **Download Salary Slip**.
3. The salary slip is generated/downloaded for the staff member.

## Make staff payment

1. Open the required staff record.
2. Click **Make Payment**.
3. Enter/select the required payment information.
4. Complete the payment.
5. The payment is recorded against the staff member.

# Attendance

The **Attendance** tab allows you to track the daily attendance of a staff member.

### Attendance statuses

- **Present** – Staff member attended work.
- **Absent** – Staff member was absent.
- **Half Day** – Staff member worked for part of the day.
- **Paid Leave** – Staff member is on paid leave.
- **Weekly Off** – Staff member has a scheduled weekly day off.

## View attendance

1. Open the required staff record.
2. Select the **Attendance** tab.
3. Select the required month.
4. Review the attendance summary.
5. Review the daily attendance records.

The attendance summary displays counts for:

| Status | Description |
| --- | --- |
| All | Total attendance records for the selected period. |
| Present | Number of days marked present. |
| Absent | Number of days marked absent. |
| Half Day | Number of half-day records. |
| Paid Leave | Number of paid-leave records. |
| Weekly Off | Number of weekly-off records. |

## Update attendance

1. Open the **Attendance** tab.
2. Select the required date.
3. Use the available attendance options.
4. Select the appropriate attendance status.
5. Save/update the attendance record if required.

# Payroll

The **Payroll** tab contains salary-related information for the staff member.

Use this section to review payroll information based on the configured salary and salary cycle.

## Transactions

The **Transactions** tab provides staff-related financial transaction information.

Use this section to review payments or other transactions associated with the staff member.

# Edit staff

1. Open **Staff**.
2. Select the required staff member.
3. Click **Edit**.
4. Update the required information.
5. Save the changes.

# Delete staff

1. Open the required staff record.
2. Click the **Delete** icon.
3. Confirm the deletion, if prompted.

<Note>
  Deleting a staff record may affect related staff information and transactions. Verify the record before deleting it.
</Note>

# FAQs

### Can I update staff details after creating a staff member?

Yes. Open the staff record and use the **Edit** option.

### Can I track staff attendance?

Yes. The **Attendance** tab allows you to view and manage daily attendance.

### Can I mark a staff member as present or absent?

Yes. Attendance records provide options for **Present**, **Absent**, **Half Day**, **Paid Leave**, and **Weekly Off**.

### Can I download a salary slip?

Yes. Open the staff details page and click **Download Salary Slip**.

### Can I make a salary payment from the Staff module?

Yes. Use the **Make Payment** option available on the staff details page.

### Can I view staff transactions?

Yes. Staff-related transactions can be viewed from the **Transactions** tab.

### Can I manage salary cycles?

Yes. A salary cycle can be selected while adding or configuring a staff member.

### What information is required to add a staff member?

The required fields shown in the Add Staff form include **Name, Mobile Number, Salary Payout Type, Salary, and other applicable salary information**.
