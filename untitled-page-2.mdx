# **Record and manage products returned by customer**

<Note>
  Sales returns allow you to record items returned by customers and optionally associate the return with an existing sales invoice.
</Note>

## Overview

The Sales returns module allows you to record products returned by customers. You can select a customer, optionally link the return to a sales invoice, add the returned items, and review the return amount.

You can use this module to:

- Create a sales return
- Select a customer
- Set the return date
- Optionally select a sales invoice
- Add returned items
- Specify item quantities
- Review prices, discounts, and taxes
- Add notes
- Add terms and conditions
- Review the grand total
- Add a signature
- Create the sales return

## Before you start

- **Permission needed:** Access to the **Sales returns** module.
- **Settings to review:** Make sure customers, items, tax settings, and sales invoices are available before creating a sales return.

Key concepts

| Term | Meaning |
| --- | --- |
| Sales return | A record of products returned by a customer. |
| Customer | The party returning the purchased products. |
| Return date | The date on which the return is recorded. |
| Sales invoice | An existing sales invoice that can optionally be associated with the return. |
| Tax category | Specifies the applicable tax category for a returned item. |
| Grand total | The total calculated amount of the sales return. |

# Common workflows

## Create a sales return

1. Open **Sales returns** from the navigation menu.
2. Click **New** or **Create Sales Return**.
3. Select the **Return Date**.
4. Select the **Customer** using **Search Customer**.
5. Optionally select an existing **Invoice**.
6. Add the returned items.
7. Enter the quantity for each returned item.
8. Review the price, discount, and tax details.
9. Add **Notes**, if required.
10. Add **Terms and Conditions**, if required.
11. Review the **Grand Total**.
12. Add a signature, if required.
13. Click **Create Sales Return**.

Field reference

| Field | Required | What it does |
| --- | --- | --- |
| Sales Return Number | System-generated | Displays the sales return number assigned by the system. |
| Return Date | Yes | Specifies the date of the sales return. |
| Customer | Yes | Selects the customer associated with the return. |
| Billing Address | — | Displays the customer's billing address. |
| Shipping Address | — | Displays the customer's shipping address. |
| Invoice | No | Optionally associates the return with an existing sales invoice. |
| Filter by Category | No | Filters available products by category. |
| Search for existing products | No | Searches for products to add to the return. |
| Quantity | Yes for added items | Specifies the quantity being returned. |
| Notes | No | Adds additional information about the return. |
| Terms and Conditions | No | Adds applicable terms and conditions. |
| Grand Total | System-calculated | Displays the total amount of the sales return. |
| Signature | No | Allows a signature to be added to the return document. |

# FAQs

### What is a sales return?

A sales return records products that are returned by a customer.

### Is selecting an invoice mandatory?

No. The **Invoice** field is marked as **Optional**.

### Can I add multiple returned items?

Yes. You can add products to the **Items** section and specify the quantity being returned.

### Is the Sales Return Number entered manually?

No. The Sales Return Number is **automatically assigned when the return is saved**.

### Can I add notes to a sales return?

Yes. You can add additional information in the **Notes** field.
