---
title: "Saved Dashboards"
---

View and manage dashboards saved from reports for quick access to frequently used business insights.

<Note>
  Saved dashboards contain reports or visualizations that have been saved for later access.
</Note>

## Overview

The **Saved Dashboards** module allows you to view dashboards that have been previously saved.

Each saved dashboard is displayed as a card containing a preview of the dashboard, its name, creation details, and available actions.

You can use this module to:

- View saved dashboards
- Open a saved dashboard
- Review the dashboard preview
- View the dashboard name and creation details
- Delete a saved dashboard
- Refresh the saved dashboard list

## Before you start

- **Permission needed:** Access to the Saved Dashboards module.
- **Saved dashboard:** At least one dashboard must be saved before it appears in this section.

## Key concepts

| Term | Meaning |
| --- | --- |
| Saved dashboard | A dashboard or report visualization saved for future access. |
| Dashboard preview | A visual preview of the saved dashboard. |
| Created on | The date and time when the dashboard was saved. |
| Created by | The business or user associated with the saved dashboard. |
| Chat | Option available on a saved dashboard for interacting with the dashboard/report, when supported. |

## Saved dashboard cards

Each saved dashboard is displayed as a separate card.

A card can contain:

- Dashboard preview
- Dashboard name
- Created date and time
- Business information
- **Chat** option
- **Delete** option

For example, the page may display saved dashboards such as:

- **Top 10 Customers by Revenue**
- **Last 10 Invoices by Total Amount**

## Common workflows

### View saved dashboards

1. Open **Saved Dashboards** from the navigation menu.
2. Review the available saved dashboard cards.
3. Select the dashboard you want to view.
4. Open the dashboard to review its details.

### Open a saved dashboard

1. Open **Saved Dashboards**.
2. Locate the required dashboard.
3. Select the dashboard card.
4. Review the saved report or visualization.

### Use Chat

1. Open **Saved Dashboards**.
2. Locate the required dashboard.
3. Click **Chat**, if available.
4. Use the available interaction to work with the saved dashboard.

### Delete a saved dashboard

1. Open **Saved Dashboards**.
2. Locate the dashboard you want to remove.
3. Click the **Delete** icon.
4. Confirm the deletion, if a confirmation message is displayed.

### Refresh saved dashboards

1. Open **Saved Dashboards**.
2. Click the **Refresh** icon in the upper-right corner.
3. The saved dashboard list is refreshed.

## Field reference

| Field / Action | What it does |
| --- | --- |
| Dashboard preview | Displays a visual preview of the saved report/dashboard. |
| Dashboard name | Identifies the saved dashboard. |
| Created date and time | Shows when the dashboard was saved. |
| Business | Shows the business associated with the saved dashboard. |
| Chat | Opens the available chat interaction for the dashboard. |
| Delete | Removes the saved dashboard. |
| Refresh | Refreshes the saved dashboard list. |

## FAQs

### What is a Saved Dashboard?

A Saved Dashboard is a report or visualization that has been saved so it can be accessed again later.

### Where can I find my saved dashboards?

Open **Saved Dashboards** from the navigation menu.

### Can I delete a saved dashboard?

Yes. Use the **Delete** icon on the required dashboard card.

### Can I interact with a saved dashboard?

Yes. The **Chat** option is available on supported saved dashboards.

### What happens if I refresh the page?

The Saved Dashboards list is refreshed to display the latest available saved dashboards.
